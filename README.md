Текущее состояние: **Этап 3 (VFS в оперативной памяти)**.

## 1. Общее описание (Этап 3: VFS)

На третьем этапе реализована виртуальная файловая система (VFS) в оперативной памяти:
- **Формат архива:** JSON-структура, загружаемая напрямую в древовидную модель объектов (`VfsNode`) без создания временных файлов на диске.
- **Хранение данных:** содержимое файлов кодируется и декодируется с использованием формата **base64**.
- **Метаданные:** для каждого каталога и файла поддерживаются:
  - права доступа (`permissions`, например `rwxr-xr-x`, `rw-r--r--`);
  - владелец (`owner`, например `root`, `student`, `deploy`);
  - время модификации (`mtime`);
  - размер в байтах (`size`, рассчитывается автоматически из base64-данных).
- **Отладочный вывод структуры VFS:** при передаче параметра `--vfs <путь>` эмулятор при старте печатает полное дерево файловой системы со всеми метаданными.
- **Тестовые наборы данных (`vfs_data/`):**
  - `vfs_minimal.json` — минимальный архив с одним файлом;
  - `vfs_medium.json` — типовая структура с папкой `docs` и файлами;
  - `vfs_deep.json` — структура с глубокой вложенностью ($\ge 3$ уровней каталогов);
  - `vfs_corrupted.json` — поврежденный файл для проверки обработки ошибок.
- **Автоматизация тестирования:**
  - `os_scripts/test_vfs_variants.sh` — проверка всех вариантов VFS из командной строки ОС;
  - `tests/test_stage3.py` — unit-тесты операций загрузки, навигации по путям и метаданных.

## 2. Параметры командной строки

```bash
./run.sh --vfs vfs_data/vfs_medium.json --script emulator_scripts/stage3_demo.txt
# или:
make run
```

### Поддерживаемые команды эмулятора
1. **`conf-dump`** — вывод параметров текущей конфигурации.
2. **`source <файл>`** (или `run-script <файл>`) — выполнение скрипта построчно из ввода пользователя.
3. **`ls`**, **`cd`**, **`cat`**, **`rev`**, **`touch`**, **`mv`** — команды-заглушки (полная интеграция с VFS — на этапах 4 и 5).
4. **`exit`** — завершение работы эмулятора.


  ```bash

  ```
- Проверка загрузки вариантов VFS и метаданных (Этап 3):

  ```bash
  make lint
  ```
- Полная проверка проекта:
  ```bash
  make check
  ```
- Запуск приложения:
  ```bash
  make run
  ```
