# Эмулятор командной оболочки ОС (Вариант №8)

Проект разработан в рамках дисциплины «Конфигурационное управление» (РТУ МИРЭА, преподаватель П.Н. Советов).

Вариант №8: Эмулятор командной строки UNIX-подобной операционной системы.
Текущее состояние: **Этап 1 (REPL)**.

---

## 1. Общее описание (Этап 1: REPL)

На первом этапе разработан минимальный прототип эмулятора:
- Графический интерфейс (GUI) на базе библиотеки Tkinter с цветовой схемой терминала.
- Формирование заголовка окна на основе реальных данных системы: `Эмулятор - [username@hostname]`.
- Парсер командной строки с поддержкой раскрытия переменных окружения (`$VAR`, `${VAR}`) и строгой валидацией синтаксиса.
- Команды-заглушки: `ls` и `cd` (выводят своё имя и переданные аргументы).
- Команда завершения работы: `exit`.

---

## 2. Описание функций и настроек

### Поддерживаемые команды
1. **`ls [аргументы...]`** — команда-заглушка, выводящая имя команды и список переданных параметров.
2. **`cd [аргументы...]`** — команда-заглушка, выводящая имя команды и целевой путь.
3. **`exit`** — завершает работу эмулятора и закрывает графическое окно.

### Раскрытие переменных окружения и синтаксис
- Переменные окружения реальной ОС вида `$VAR` и `${VAR}` (например, `$HOME`, `$USER`) автоматически раскрываются, в том числе внутри двойных кавычек.
- Запрещён ведущий пробел перед командой: ввод `  ls` возвращает ошибку `syntax error: unexpected leading whitespace`.
- Непарные кавычки (например `ls "path`) вызывают ошибку синтаксиса.

---

## 3. Команды для сборки и запуска тестов

Для запуска требуется Python 3 с поддержкой Tkinter.

- Запуск unit-тестов:
  ```bash
  make test
  ```
- Проверка соответствия стандартам оформления кода (критерии П.Н. Советова):
  ```bash
  make lint
  ```
- Полная автоматическая проверка (стиль + тесты):
  ```bash
  make check
  ```
- Запуск приложения:
  ```bash
  make run
  # или: ./run.sh
  ```

## 4. Примеры использования

```bash
[zhes@MacBook-Pro-Evgenij-2.local /]$ ls -la $HOME

[zhes@MacBook-Pro-Evgenij-2.local /]$ cd /tmp

[zhes@MacBook-Pro-Evgenij-2.local /]$   ls
syntax error: unexpected leading whitespace

[zhes@MacBook-Pro-Evgenij-2.local /]$ exit
logout
```
