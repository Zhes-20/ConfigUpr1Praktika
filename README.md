# Эмулятор командной оболочки ОС (Вариант №8)

Проект разработан в рамках дисциплины «Конфигурационное управление» (РТУ МИРЭА).

Вариант №8: Эмулятор командной строки UNIX-подобной операционной системы.  
Текущее состояние: **Этап 5 (Финальная версия)**.

---

## 1. Общее описание

Эмулятор командной строки UNIX-подобной операционной системы с графическим интерфейсом (GUI) на основе Tkinter. Работает с виртуальной файловой системой (VFS), загружаемой из JSON-файла непосредственно в оперативную память без создания временных файлов на диске.

### Реализованные возможности
- Графический интерфейс с цветовой схемой терминала.
- Заголовок окна на основе реальных данных ОС: `Эмулятор - [username@hostname]`.
- Парсер командной строки с раскрытием переменных окружения (`$VAR`, `${VAR}`).
- Строгая валидация синтаксиса (пробел перед командой, незакрытые кавычки, пустые переменные).
- Конфигурация через аргументы командной строки (`--vfs`, `--script`).
- Виртуальная файловая система в памяти с хранением данных в base64 и поддержкой метаданных (права, владелец, размер, время модификации).
- Выполнение стартовых скриптов при запуске.
- Команды файловой системы: `ls`, `cd`, `cat`, `rev`, `touch`, `mv`.
- Служебные команды: `conf-dump`, `source`, `exit`.

## 2. Параметры командной строки

```bash
./run.sh --vfs <путь_к_vfs.json> --script <путь_к_скрипту>
# или:
./run.sh -v <путь_к_vfs.json> -s <путь_к_скрипту>
```

| Параметр | Описание |
|----------|----------|
| `--vfs`, `-v` | Путь к JSON-файлу виртуальной файловой системы |
| `--script`, `-s` | Путь к стартовому скрипту с командами эмулятора |

---

## 3. Поддерживаемые команды

| Команда | Описание |
|---------|----------|
| `ls [путь...]` | Вывод содержимого одного или нескольких каталогов VFS (опции не поддерживаются) |
| `cd <путь>` | Смена текущего каталога (поддержка `.`, `..`, абсолютных и относительных путей) |
| `cat <файл> [файл2...]` | Вывод содержимого файлов (декодирование base64) |
| `rev <файл> [файл2...]` | Посимвольный разворот строк файла |
| `touch <файл> [файл2...]` | Создание пустого файла в VFS или обновление времени изменения существующего |
| `mv <источник> <назначение>` | Перемещение или переименование файлов и каталогов в VFS (только в памяти) |
| `conf-dump` | Вывод текущих параметров конфигурации |
| `source <файл>` | Выполнение скрипта из интерактивного ввода |
| `exit` | Завершение работы эмулятора |

## 4. Команды для сборки и запуска

```bash
make test      # Запуск unit-тестов
make lint      # Проверка оформления кода
make check     # Проверка оформления и unit-тесты
make test-cli  # Запуски эмулятора со всеми параметрами CLI
make test-vfs  # Запуски эмулятора с вариантами VFS
make run       # Запуск эмулятора с VFS и демо-скриптом
```

Сборка не требуется: нужен только Python 3.9+ с Tkinter.

`make test-cli` и `make test-vfs` выполняют скрипты из `os_scripts/`. Каждый запуск открывает окно эмулятора. Окно закрывается само, если стартовый скрипт дошёл до `exit`. Если скрипт остановился на ошибке, окно остаётся открытым для просмотра: закрыть его командой `exit`.

### Стартовые скрипты

Стартовый скрипт останавливается при первой ошибке, поэтому каждый пример ошибки лежит в отдельном файле.

| Файл | Назначение |
|------|------------|
| `emulator_scripts/stage1_demo.txt` | REPL, переменные окружения, ошибка разбора |
| `emulator_scripts/stage2_demo.txt` | `conf-dump` |
| `emulator_scripts/stage3_demo.txt` | Работа с VFS, ошибка пути |
| `emulator_scripts/stage4_demo.txt` | `ls`, `cd`, `cat`, `rev` |
| `emulator_scripts/stage5_demo.txt` | `touch`, `mv` |
| `emulator_scripts/vfs_minimal_demo.txt` | Минимальная VFS |
| `emulator_scripts/vfs_deep_demo.txt` | VFS с 3 уровнями вложенности |
| `emulator_scripts/script_syntax_error.txt` | Остановка на синтаксической ошибке |
| `emulator_scripts/errors/*.txt` | По одной ошибке каждой команды |

## 5. Структура проекта

```
├── src/                         # Исходный код эмулятора
│   ├── __init__.py
│   ├── main.py                  # Точка входа
│   ├── config.py                # Конфигурация и разбор CLI-аргументов
│   ├── shell_core.py            # Ядро: парсер, диспетчер команд, управление состоянием
│   ├── commands.py              # Реализация команд (ls, cd, cat, rev, touch, mv)
│   ├── vfs.py                   # Виртуальная файловая система в оперативной памяти
│   └── gui.py                   # Графический интерфейс на Tkinter
├── tests/                       # Unit-тесты
│   ├── test_stage1.py           # Парсер, переменные окружения, заголовок
│   ├── test_stage2.py           # Конфигурация, CLI, скрипты
│   ├── test_stage3.py           # Загрузка VFS, навигация по путям, метаданные
│   ├── test_stage4.py           # Команды ls, cd, cat, rev
│   ├── test_stage5.py           # Команды touch, mv
│   ├── test_edge_cases.py       # Краевые случаи и строгая валидация синтаксиса
│   └── test_scripts.py          # Прогон всех стартовых скриптов
├── vfs_data/                    # Тестовые JSON-образы виртуальной файловой системы
│   ├── vfs_minimal.json         # 1 файл
│   ├── vfs_medium.json          # Каталоги и файлы
│   ├── vfs_deep.json            # Глубокая вложенность (>= 3 уровней)
│   └── vfs_corrupted.json       # Поврежденный файл для проверки ошибок
├── emulator_scripts/            # Стартовые скрипты для эмулятора
│   └── errors/                  # Скрипты с примерами ошибок команд
├── os_scripts/                  # Скрипты реальной ОС: запуски эмулятора с CLI и VFS
├── check_code_style.py          # Проверка стандартов оформления кода
├── Makefile                     # Автоматизация сборки и тестирования
└── run.sh                       # Скрипт запуска эмулятора
```

## 6. Примеры использования

```bash
# Запуск с VFS и стартовым скриптом
./run.sh --vfs vfs_data/vfs_medium.json --script emulator_scripts/stage5_demo.txt

# Интерактивный сеанс
[zhes@MacBook /]$ ls
docs  readme.txt

[zhes@MacBook /]$ cat readme.txt
UNIX Shell Emulator Project
Course: Configuration Management

[zhes@MacBook /]$ touch new_file.txt
[zhes@MacBook /]$ ls
docs  new_file.txt  readme.txt

[zhes@MacBook /]$ mv new_file.txt docs
[zhes@MacBook /]$ ls docs
new_file.txt  notes.txt

[zhes@MacBook /]$ rev readme.txt
tcejorP rotalumE llehS XINU
tnemeganaM noitarugifnoC :esruoC

[zhes@MacBook /]$   ls
syntax error: unexpected leading whitespace

[zhes@MacBook /]$ mv docs readme.txt
mv: cannot move 'docs': Нельзя заменить файл каталогом

[zhes@MacBook /]$ exit
logout
```
